# Cadastro de Pessoas

Projeto inicial de estudo em Java e Spring Boot, feito em 2025 durante a graduação em ADS. Está em estágio inicial e não é um projeto de produção.

## O que existe hoje
- Spring Boot 3.5.3 e Java 17, com Maven.
- Entidade `PessoaModel` (id, nome, e-mail e idade) mapeada com JPA, e uma entidade de funções.
- Endpoint de teste: `GET /boasvindas`.

## O que falta
- Configurar um banco de dados e o driver.
- Endpoints de cadastro, consulta, alteração e exclusão.
- Testes além do teste padrão.

## Como rodar
Ainda não há banco de dados nem driver configurados, então a execução completa depende disso. Este README será atualizado quando houver.
